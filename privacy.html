Privacy Policy

Deep Wiring Factory is operated by the owner of the Deep Wiring YouTube channel for personal channel operations. This policy covers the desktop tool and this informational website.

Google and YouTube data

The desktop tool uses YouTube API Services. When the owner grants access in a Google browser window, the tool receives OAuth credentials. It uses YouTube Data API access to identify the connected channel, check upload and processing status, and transmit approved videos and their metadata, including titles, descriptions, tags, visibility and any scheduled release time. The tool can also retrieve view, like and comment counts and use YouTube Analytics access for aggregate watch time and average view percentage for its recorded uploads.

The OAuth credentials are saved in restricted local files and used to renew access to Google’s APIs. The tool stores local upload receipts, including YouTube video IDs and release details, and can cache statistics locally. The local planner can use cached performance data when ranking topics. The dashboard displays selected operational state to the owner and does not send OAuth credentials to the browser.

Video files and upload metadata are sent to Google through the YouTube API when an upload is authorized. The operator does not sell Google user data, use it for advertising, or transfer it to other parties for their own use. The website does not receive YouTube account data. Use and transfer of information received from Google APIs is subject to the Google API Services User Data Policy, including its Limited Use requirements. Google’s handling of data is described in the Google Privacy Policy.

Storage, access and deletion

The local installation does not automatically purge analytics or upload receipts. The operator manages refresh and deletion of locally stored API data. To withdraw authorization, remove Deep Wiring Factory in Google Account permissions. Contact the operator to request deletion of related local data. Deleting local records does not remove a video or other data from YouTube. Manage or delete YouTube videos in YouTube Studio.

Public website

These static pages have no forms, analytics scripts or advertising trackers. GitHub Pages logs visitor IP addresses for security. See the GitHub Privacy Statement.
